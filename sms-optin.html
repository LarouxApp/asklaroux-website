SMS opt-in

This page documents how users consent to receive SMS messages from Laroux, for carrier and messaging-provider review.

The Laroux phone sign-in screen, showing the consent disclosure.

How users opt in

Laroux uses SMS solely to deliver one-time verification codes when a user chooses to sign in with a phone number. Opt-in happens inside the app, at the point the user enters their number:

  1. The user opens Laroux to the sign-in screen.
  2. They begin typing their own phone number into the sign-in field. Once enough digits are entered for the app to recognize it as a phone number, the screen presents the phone verification option.
  3. Before requesting a code, they see the consent disclosure shown in the screenshot, directly below the number field.
  4. They tap Send Code, which sends a single verification code to their number.

Consent language shown

The following disclosure appears on screen, above the Send Code button, before any message is sent:

By entering your phone number, you agree to receive a one-time verification code via SMS. Message and data rates may apply. View our Privacy Policy and Terms of Service.

The Privacy Policy and Terms of Service are linked directly from that disclosure.

Message the user receives

Users receive a single verification code per request. No marketing or promotional messages are sent. Example:

Your Laroux verification code is 123456. Reply STOP to opt out, HELP for help. Msg & data rates may apply.

Opting out

Users can reply STOP at any time to opt out of further messages. Because messages are only sent in direct response to a user-initiated sign-in request, no messages are sent unless the user actively requests a code.
